# Tales of Maj'Eyal Archipelago 1.0.2

1.0.2 adds reviewed protection for talent categories whose real gameplay dependencies are not represented by ToME's formal talent requirements, plus in-game resource display and paid shop fixes. The mailbox and generated-contract protocols are unchanged. Install the matching [addon](../release/tome-archipelago.teaa) and [APWorld](../release/tome.apworld) together.

## Dependency model

The compiled catalog is now schema 4 and can express:

- exact support dependencies;
- reusable functional capabilities with preferred existing providers and deterministic fallbacks;
- same-tree anchor talents that bootstrap a category's core mechanic.

Examples covered in this release include Shadows for Advanced Shadowmancy/One With Shadows, actual summon creation for advanced/augmentation Summoning, another Chronomancy spell for Spellbinding, combo generation for Finishing Moves and Unarmed Discipline, alchemist-gem creation for Explosives, Insanity generation for Beyond Sanity, entropic backlash for Oblivion, undead minions for Master Necromancer, native Alchemist Golem creation for Advanced Golemancy, and mutual Possession/Bodies Reserve support.

Selected trees such as Shadows, Temporal Hounds, Thought-Forms, Golemancy, several Necromancer summon trees, and several Demented mechanic trees request paid anchor ranks through Archipelago's multiworld early-item pool. Dreaming, Nightmare, and prodigy-granted Thaumaturgy now have early anchors. Mandatory Combat Training requests two early ranks each of Combat Accuracy, Weapons Mastery, Dagger Mastery, and Exotic Weapons Mastery. An external hard dependency may still precollect a requested rank when another tree cannot function without it.

Finger of Death now skips its optional body capture for AP characters until both Possess and Bodies Reserve are known, avoiding a missing body-storage access.

The early advancement cutoff now has a minimum of level 3. Generation extends the effective cutoff only if a seed needs more ToME checks usable by its requested early talents; priority boss checks are excluded because Archipelago's early pass cannot put useful talents there. Early placement rules apply only during that pass, so additional copies of a requested talent remain legal at later checks. Native Archipelago fill tests cover tight windows, repeated copies, boss priority, and mixed-world placement.

When a functional dependency has several providers, generation first uses a provider category already available at character creation. Only if no such provider exists is the reviewed fallback category added as support.

## Golemancy

Golemancy uses ToME's native behavior rather than custom entity construction. When Advanced Golemancy requires a golem, its support rule precollects `Golem Power`; native ToME then grants `Refit Golem`, whose callback creates the Alchemist Golem. Golemancy selected on its own instead requests an early paid rank of `Golem Power`.

## In-game fixes

- Resource bars appear when the character learns a talent that uses the resource, in both Classic and Minimalist displays. The resource pool talents remain learned for native mechanics.
- Shop parcels are rechecked when purchase is confirmed, preventing duplicate or stale purchases and refunding gold if recording fails. Restored saves reconcile server-checked shop locations.

The packaged 1.0.2 APWorld was compiled from a fresh ToME 1.7.6 runtime export with Steam-enabled Possessor content. It retains the 291 tree keys and 1,232 item IDs present in the 1.0.1 catalog.

The release source passed 231 Python/Lua tests and 34 native Archipelago tests. The archives passed integrity and staged-source checks. See the [validation report](VALIDATION_REPORT.md) for the recorded results and remaining live-game qualification.

## Compatibility

- Runtime export remains schema 2.
- Generated contract/slot data remains schema 3.
- Mailbox protocol remains 1.
- Saved `archipelago_state` remains schema 3.
- Stable item IDs and location-ID rules are unchanged.
- Existing generated 1.0.x seeds remain valid and are not retroactively rewritten.
- New 1.0.2 seeds can have different support trees, precollected ranks, item/location counts, catalog hashes, and contract hashes from older releases using the same YAML/RNG seed.

The APWorld intentionally rejects catalog-schema-3 files instead of silently ignoring the new dependency policy.
