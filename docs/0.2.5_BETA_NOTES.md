# v0.2.5 beta implementation notes

This pass broadens the ToME location economy while keeping native loot additive.

## Curated world checks

- Added exploration checks for the ten standard T1/T2 dungeons and major later campaign dungeons.
- Added major deterministic campaign quest checks, including the four universal T2 zone objectives.
- Added the missing T1 guardian checks for Norgos Lair, Scintillating Caves, Rhaloren Camp, and Heart of the Gloom.
- The ten requested base T1/T2 guardians are `PRIORITY` Archipelago locations.

## Early-item safety

- Advancement rewards through level 10 are early-safe.
- The ten T1/T2 exploration checks, ten priority guardian checks, and four T2 zone-quest checks are early-safe.
- Explicit `early_items` / `local_early_items` are forbidden from every other ToME location.
- On the known seed 1 catalog this currently exposes 87 early-safe locations.

## Paid shop parcels

- Added three static paid AP parcels to each ordinary merchant in Derth, Last Hope, Elvala, Shatur, and Gates of Morning.
- Zigur, Iron Council, Angolwen, special quest merchants, and quest-gated services are intentionally excluded.
- Current ordinary-shop manifest: 42 merchants / 126 parcel locations.
- Prices: early towns 50/100/200 gold; Last Hope 100/200/400; Gates of Morning 250/500/1000.
- Parcel checks are `EXCLUDED`, so Archipelago will not place progression or useful items there.
- One Vitality filler item is added to the item pool per parcel so excluded checks are always fillable without sacrificing build items.
- Parcels are injected into the live store UI, are unaffected by store restocks, are never transferred into player inventory, and disappear permanently once checked.

## Validation

- Python suite: 94 passed, 1 optional Lua execution module skipped because `lupa` is unavailable in this environment.
- Real ToME runtime validation is still required for the store UI superload and quest-status hook.
