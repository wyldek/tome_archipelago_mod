# v0.2.0 beta implementation notes

This is the first pass that replaces the intentionally narrow smoke-test catalog with the full runtime-driven design.

## Rules implemented

- YAML tree counts mean **random** class/generic trees.
- `technique/combat-training` is mandatory and added **in addition** to the configured generic count.
- Every paid rank in selected trees is a specific AP item.
- Specific +5 stat packages replace distributable stat points.
- Specific prodigies replace prodigy-point currency.
- Runtime prodigies are broadly eligible; there is no blanket evolution blacklist.
- Selected prodigies can expand the seed with rank items from categories they grant.
- Prodigy-category ranks received early remain pending until the category is enabled.
- Evolution/prodigy native free ranks in AP-managed trees are normalized back to the server-owned AP rank count.
- All native talent/prodigy/equipment requirements are bypassed for the AP character.
- AP progression reconstructs from the slot receipt history after character death/restart.
- Native ToME equipment/loot is never shuffled or replaced.

## Catalog changes

The v0.2 addon exports schema 2 metadata. The compiler builds its ordinary random-tree pool from player-facing subclass descriptors exported by the installed ToME runtime, rather than the old 29-tree mana/stamina whitelist. Prodigy-only categories may exist in the compiled master catalog but are not eligible for the ordinary random-tree roll.

The old schema-1 export and catalog are intentionally incompatible with this build. Regenerate `runtime-export.json` after installing this addon.

## Mandatory Combat Training

A default `6/4` seed means:

```text
6 random class trees
4 random generic trees
+ Technique / Combat Training
```

Combat Training itself remains AP-managed. Its seven 5-rank talents contribute 35 rank items to the default seed budget.

## Prodigy expansion policy

The initial reviewed prodigy expansion metadata includes special handling for examples such as High Thaumaturgist, Technomancer, Fallen, Lich, Tricks of the Trade, Worldly Knowledge, and Rak'Shor's Cunning. Native effects still execute unless deliberately suppressed to avoid an interactive/free-currency conflict; AP then restores/normalizes the ranks that belong to the seed.

This metadata still requires real-game qualification for each evolution.

## Location changes

The beta now combines:

- fixed additive boss-defeat checks;
- fixed campaign/zone milestones;
- a native campaign victory check; and
- variable level-reward checks used to make the location count exactly equal the generated item pool.

The fixed beta boss manifest currently includes the alternate guardian pairs for Trollmire, Kor'Pul, Old Forest, Maze and Daikara, plus Sandworm Queen, The Master, Golbug and the four Pride leaders.

Boss observation runs after the native NPC death path. No AP code replaces or suppresses the boss's native loot, XP, artifacts, gold or quest handling.

## Resource compatibility

The addon now reads ToME's registered resource definitions and can enable the hidden pool talents/resources needed by selected trees. Baseline regeneration values are a compatibility policy for random builds and need real-game testing across unusual combinations.
