# v0.2.6 beta implementation notes

This pass makes the expanded location model configurable and removes the shop-filler inflation introduced in v0.2.5.

## New YAML options

- `zone_exploration_checks`: on/off, default on.
- `quest_checks`: `none`, `major`, or `major_and_zone` (default).
- `shop_checks`: `off` or `non_progression` (default). No excluded mode is exposed.
- `shop_checks_per_store`: 1–3, default 3.
- `early_level_max`: 1–20, default 10.
- `t1_t2_boss_priority`: on/off, default on.

## Dynamic accounting

- Paid shops no longer add Vitality filler.
- Every enabled fixed check consumes the existing shuffled reward budget.
- Level checks fill the exact remainder.
- Sparse level schedules are supported when fewer level-check slots remain than level milestones.
- Generation fails clearly if a very small build enables more fixed checks than it has shuffled rewards.

For an illustrative ordinary 6/4/5 build with 298 shuffled rewards and all default location options, the fixed manifest consumes 172 checks, leaving 126 level checks. The item pool remains 298 real build rewards with no generated Vitality copies.

## Paid shops

- The current 42-store manifest remains Derth, Last Hope, Elvala, Shatur, and Gates of Morning.
- Three parcels per store remains the default, for 126 paid checks.
- Shop locations are no longer AP `EXCLUDED`. Instead, their item rule rejects any `item.advancement`, while allowing useful/filler/trap items.
- This prevents another world's required progression from being gated by ToME gold without requiring a large filler reserve.

## Future artifact checks

A configurable artifact-check mode is intentionally deferred. The random world-artifact pool is large enough to balloon the location count substantially, and random-generation guarantees need a separate policy before it becomes a supported option.

## Validation

- Python suite: 97 passed, 1 optional Lua execution module skipped when `lupa` is unavailable.
- Real ToME runtime validation is still required for the store UI and quest-status hooks.
