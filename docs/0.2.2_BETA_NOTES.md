# v0.2.2 beta implementation notes

## AP-only antimagic/arcane coexistence

Archipelago Adventurers can roll antimagic talent trees and spell/arcane talent trees in the same seed.
Vanilla ToME treats these as mutually exclusive by maintaining `forbid_arcane` and `has_arcane_knowledge` attributes.

v0.2.2 suppresses both compatibility attributes for the Archipelago character only. This means:

- learning Antimagic or another `is_antimagic` tree does not block spells or arcane equipment;
- learning spells does not block antimagic equipment/rewards;
- mixed AP builds are not blocked from campaign portals or conversations by the vanilla antimagic flag;
- antimagic disruption is not applied merely because the same AP character knows spells;
- non-Archipelago characters retain vanilla behavior unchanged.

The underlying talents are not modified. Prodigies that explicitly check whether the actor knows `wild-gift/antimagic` still work because the category remains learned; only the mutually-exclusive identity flags are neutralized.

No catalog or seed-contract schema change is required. Existing schema-3 compiled catalogs and local-demo seeds remain valid.
