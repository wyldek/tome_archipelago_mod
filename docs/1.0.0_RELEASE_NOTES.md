# Tales of Maj'Eyal Archipelago 1.0.0

1.0.0 is the first feature-complete release of the current ToME Archipelago design.

## Highlights

- Seed-selected random class/generic talent categories plus mandatory Combat Training.
- Per-rank talent items using runtime-exported real caps and names.
- Named +5 stat packages and specific prodigy items.
- Prodigy-added categories and reviewed hard dependency support categories.
- Additive boss, zone-entry, quest, shop, advancement, and victory locations.
- Paid shop parcels reveal their scouted item and recipient but cannot contain logical progression.
- AP-only antimagic/arcane compatibility handling for mixed random builds.
- Ordered receipt-prefix persistence, same-slot reconstruction, mailbox locking, and reconnect catch-up.
- Mailbox root corrected to `/archipelago` (normally `...\T-Engine\4.0\tome\archipelago`) with schema-2 marker validation.
- The historical runtime `offline-policy.json` requirement has been removed; offline-isolation scripts are optional developer tools only.

## Compatibility

- Tales of Maj'Eyal 1.7.6
- Archipelago 0.6.7
- Standalone source-client Python: 3.11.9 through 3.13

The `.teaa` and `.apworld` for a release should be built from matching source. The APWorld catalog must be compiled from a fresh schema-2 runtime export produced by the current addon.

## Qualification status

Core bidirectional sync and reconnect catch-up have been smoke-tested in the real game, including precollected starter ranks and level/zone checks. Full campaigns, every optional location, broad shared multiworld play, and every prodigy/resource combination remain incompletely qualified. See `docs/IMPLEMENTATION_STATUS.md` and `docs/VALIDATION_REPORT.md`.
