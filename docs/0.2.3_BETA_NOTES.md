# v0.2.3 beta implementation notes

## Baseline ranged utilities

Archipelago Adventurers now receive ToME's hidden one-rank `Shoot` and `Reload` utility talents at AP character initialization. They are infrastructure only and never enter the Archipelago item pool or location budget. `Shoot` is also assigned as the default ranged left-click action, matching native ranged-class behavior.

The audit intentionally does **not** make every hidden helper universal:

- `Attack` is already guaranteed by `mod.class.Actor`.
- Resource-pool talents are enabled from selected-tree resource metadata.
- `Empty Hand` is automatically granted by ToME when an unarmed talent is learned.
- hidden stances/autolearn helpers remain tied to their owning talents.
- `Spacetime Tuning` is automatically granted when a paradox-using talent is learned.

This is a runtime-only compatibility/QoL change. Catalog schema 3 and existing compiled catalogs remain valid.
