# v0.2.7 beta

- Paid shop checks reveal the actual Archipelago item before purchase instead of displaying sealed parcels.
- Cross-world shop items include the recipient player name in the store entry.
- The bridge requests `LocationScouts` for all enabled shop locations with `create_as_hint: 0`; scouting does not create public hints.
- `client.json` now carries validated `scouted_locations` metadata.
- Local demo publishes deterministic scout metadata for its shop placements.
- If scout information is not available yet, the corresponding paid shop item is not displayed.
